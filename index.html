विद्यार्थी सूची

📚 कक्षा के विषय

हर कक्षा के लिए विषय अलग रख सकते हैं।

📝 परीक्षा/टेस्ट के अंक

एक ही परीक्षा में विषय बदलकर हर विषय के अंक सेव करें। पुराने अंक edit करके फिर से Save किए जा सकते हैं।

🏆 कक्षा परिणाम और रैंक

रैंक केवल उन विद्यार्थियों की बनेगी जिनके सभी निर्धारित विषयों के अंक दर्ज हैं। अधूरे रिकॉर्ड को “अपूर्ण” दिखाया जाएगा। बराबर प्रतिशत पर समान रैंक मिलेगी।

📄 विद्यार्थी रिपोर्ट कार्ड

PDF बटन दबाने पर print window खुलेगी। वहाँ Save as PDF चुनकर रिपोर्ट PDF में सेव करें। मोबाइल और लैपटॉप दोनों पर काम करेगा।

💾 Backup / Restore

Backup डाउनलोड करके सुरक्षित रखें। दूसरे कंप्यूटर पर Restore किया जा सकता है।

🔄 App Update

App का code online update हो सकता है। विद्यार्थी, विषय और अंक localStorage में अलग रहते हैं, इसलिए सामान्य code update से data delete नहीं होता।
